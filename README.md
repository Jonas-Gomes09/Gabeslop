## Executando o código:
1. Primeiramente na pasta raiz do projeto, execute este comando para instalar os módulos requeridos pela API
```
npm install
```

2. Execute este comando para executar o servidor com TSX watch.
```
npm run dev
```

### Acessando o website

Você pode acessar o site digitando "http://localhost:35000" no seu navegador.

## Executando testes:
Execute o seguinte comando para realizar testes com o vitest.
```
npm run test
```



## Usando o website:

1. Quando o site pede seu e-mail, não é necessário que seja real. O email pode ser escrito de qualquer forma (desde que contenha o caractére @). O site não verificará se o e-mail realmente existe, pois afinal, não é um produto real.

2. Para acessar as rotas de admin, preencha o login com as seguintes informações:

Email:
```
admin@gabeslop.com
```

Senha:
```
admin123
```
